# Fall Guys Archive

Website of the Fall Guys archive

Visit us: https://fga.floyzi.dev

## Development

**Requirements**: [Node.js](https://nodejs.org) installed

```bash
git clone https://github.com/Obed-Guys-Corp/fg-archive
cd fg-archive

# Install node dependencies
npm install
```

#### Scripts

`npm run dev` - Start dev server  
`npm run build` - Production build to `dist/`  
`npm run preview` - Preview production build from `dist/`  
`npm run prettier` - Format code with Prettier
